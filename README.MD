# Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project implements a **Customer Segmentation model using K-Means Clustering** to group customers into different segments based on their characteristics and spending behavior.

The project focuses on analyzing customer data and identifying meaningful customer groups using unsupervised machine learning.

## 🎯 Objective

The main objective of this project is to:

* Analyze customer data
* Identify meaningful customer segments
* Apply K-Means Clustering
* Determine the optimal number of clusters
* Visualize and analyze the resulting customer groups

## 📊 Dataset

The project uses the **Mall Customers dataset**, which contains customer information used for segmentation analysis.

Important features include:

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score

## 🤖 Machine Learning Model

**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters.

The project uses the **Elbow Method** to help determine the optimal number of clusters and uses **Silhouette Score** for cluster evaluation.

## 🔄 Project Workflow

1. Load the customer dataset
2. Explore and understand the data
3. Perform data preprocessing
4. Select relevant features
5. Standardize the features
6. Determine the optimal number of clusters
7. Apply K-Means Clustering
8. Evaluate the clusters
9. Visualize the customer segments
10. Analyze the resulting clusters
